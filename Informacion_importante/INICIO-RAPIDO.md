# ⚡ INICIO RÁPIDO

## 🚀 Primera vez (instalación)

1. Abre PowerShell aquí (clic derecho en la carpeta → "Abrir en Terminal")
2. Ejecuta:
   ```
   npm install
   ```
3. Espera 30 segundos mientras se instalan las dependencias

---

## 🎯 Uso diario

### Opción 1: Doble clic en `INICIAR.bat`
- Simplemente haz doble clic en el archivo **INICIAR.bat**
- El sistema abrirá el navegador automáticamente
- Si el puerto 3000 está ocupado, puede abrir en otro puerto (3001-3005)

### Opción 2: Comando manual
1. Abre PowerShell aquí
2. Ejecuta:
   ```
   npm start
   ```
3. Abre tu navegador en: **http://localhost:3000**

---

## 📊 Usar Excel

### Acceder al menú
- En la barra lateral izquierda, pasa el mouse sobre el icono **💾**
- Aparecerá un menú con las opciones de Importar/Exportar

### Exportar ⬇️
- Haz clic en **⬇️ Exportar** en el menú desplegable
- Los datos se guardan automáticamente en:
  - `BaseDeDatos/BaseDeDatos.xlsx` (hoja "Trabajos" o "Productos")

### Importar ⬆️
- Haz clic en **⬆️ Importar** en el menú desplegable
- Los datos se cargan desde el archivo `BaseDeDatos/BaseDeDatos.xlsx`

---

## 📝 Archivos importantes

- **INICIAR.bat** → Hacer doble clic para iniciar
- **README.md** → Instrucciones completas
- **BaseDeDatos/BaseDeDatos.xlsx** → Archivo único con todas tus datos
  - Hoja "Trabajos" → Servicios registrados
  - Hoja "Productos" → Catálogo de productos

---

## ⚠️ Importante

- ✅ Si usas `INICIAR.bat`, usa la URL que se abre automáticamente
- ✅ Si inicias manualmente (`npm start`), usa **http://localhost:3000**
- ✅ NO abras index.html haciendo doble clic
- ✅ Para hacer backup: copia el archivo `BaseDeDatos/BaseDeDatos.xlsx`
- ✅ Para detener: presiona **Ctrl+C** en la terminal
